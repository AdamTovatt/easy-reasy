# EasyReasy.Metrics

A library for collecting, storing, and querying periodic business metrics using the snapshot model.

## Overview

EasyReasy.Metrics provides a simple framework for:
- **Collecting** metric values on a configurable schedule via registered collectors
- **Storing** timestamped metric snapshots in PostgreSQL
- **Querying** the latest value, closest-to-date, sampled ranges, and deltas between two points in time

## Quick Start

```csharp
// Register the metrics services
services.AddEasyReasyMetrics(options =>
{
    options.CollectionInterval = TimeSpan.FromHours(5);
    options.MinimumTimeBetweenCollections = TimeSpan.FromMinutes(30);
    options.InitialDelay = TimeSpan.FromSeconds(30);
});

// Register collectors
services.AddMetricCollector<ActivePoliciesCollector>();
services.AddMetricCollector<TotalCustomersCollector>();
```

## Database Schema

```sql
CREATE TABLE metric_snapshot (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    metric_key TEXT NOT NULL,
    collected_at TIMESTAMPTZ NOT NULL,
    value NUMERIC NOT NULL
);

CREATE INDEX idx_metric_snapshot_key_collected
    ON metric_snapshot (metric_key, collected_at DESC);
```
